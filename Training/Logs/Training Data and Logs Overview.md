#training/logs #note

> **Status:** Coming soon — training log index and future data import pipeline.

Hub for tracking swimming and gym sessions in `Training/Logs/`, designed to support manual Obsidian Mobile logging today and structured data imports in the future.

## Logging Workflow

- **Swimming Sessions:** Create a new note in `Training/Logs/` using `Swim Log Template`.
- **Gym Sessions:** Create a new note in `Training/Logs/` using `Gym Log Template`.

## Planned Data Import Pipeline (Pixel Watch 2 & Google Health)

Future automation will explore importing workout telemetry from **Pixel Watch 2** and **Google Health** (via Health Connect exports, Google Takeout, or Fitbit Web API) into standardized markdown summaries:

- **Swim Metrics:** Date, pool length, total distance, duration, average pace per 100m, SWOLF/stroke rate (where available), average and max heart rate.
- **Gym Metrics:** Date, session duration, average and max heart rate, paired with structured exercise sets, reps, load, and RIR.
- **Longitudinal Tracking:** Weekly swim volume, gym consistency, and shoulder/fatigue trend indicators.
